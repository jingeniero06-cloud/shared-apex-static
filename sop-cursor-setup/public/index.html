Cursor is how you ask the SOP. PowerShell is how you run it.

02 · Install Cursor

Install Cursor on this Windows PC. Sign in with your work account.

You need the desktop app, not only a browser tab of a live SOP. The live HTML pages are for reading. Cursor chat needs the folder on disk.

  1. Install Cursor from the official download.
  2. Sign in.
  3. You do not need GitHub for this kit.

03 · Open the kit folder

File → Open Folder on shared-apex-static.

That is the workspace Cursor will search. If you only open a PDF or a live URL, chat will not see the rules or scripts.

Folder to open

C:\Users\<You>\Downloads\shared-apex-static

Also fine: open Downloads\fleet if the worker junction points at this repo. Confirm docs\SOP-CONVERT-PREVIEW-CUTOVER-RESCRAPE.md is visible in the file tree.

04 · Rules load by themselves

You do not paste the SOP into every chat. The folder already teaches Cursor.

When this repo is the workspace, Cursor applies the fleet rules: WordPress on the hosting IP is source of truth, Batches 1–7 stay on Server 2, new batches use Server 1, Stay-WordPress is Azalea Park only.

05 · Chat vs Agent

Ask in Chat to learn the path. Use Agent when you want Cursor to inspect files or draft a command.

Chat

“Which path for this domain?” “Is Round Rock stay-WordPress?” Good for read-only answers.

Agent

“Show me the preview command for a new-batch domain.” It can open the SOP and scripts. You still run PowerShell yourself unless you asked it to run it.

06 · Point at a file

Type @ and pick the SOP if the answer must stay on that document.

Useful files: SOP-CONVERT-PREVIEW-CUTOVER-RESCRAPE.md, SOP-MACHINE-SETUP.md, HANDOFF.md. You can also paste a live docs URL. The folder is still stronger than a URL alone.

09 · Secrets

Never paste .env, the Cloudflare token, or vault items into chat.

Cursor can read .env from disk if it is in the workspace. Do not put the token in the prompt, Slack, or email. If chat asks for the token, stop and use the vault on the PC instead.

Do not paste CLOUDFLARE_API_TOKEN into Cursor
