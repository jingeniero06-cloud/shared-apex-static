01 · Source of truth

Live WordPress on the hosting IP — never public static

Fix copy, popups, forms, and CallRail on WP first. Then scrape. If apex already returns x-source: kv, do not scrape that public HTTPS — you would recopy stale KV.

WordPress · origin IP → HTML_FLEET + R2 → Visitor sees fleet

Proof the public host is fleet

HTTP 200 · x-source: kv · x-fleet-host: domain

x-source: kv without x-fleet-host is the old per-site Worker.

03 · Path A · New convert

Apex stays WordPress until QA signs off

client.com WP → scrape via origin IP → static.client.com → apex + www after QA
  • Stay-WP exclude checked · WPVivid backup
  • Attach static.{domain}/* only
  • Adam /provision-originless is preview-only
  • Cutover needs -IConfirmApexCutover
cd fleet\preview
powershell -File .\scripts\Invoke-PreviewStaticOnFleet.ps1 -SitesCsv .\sites\YOUR.csv -OriginIp 174.136.29.214 -WorkerName fleet-static-worker
# Server 1: -OriginIp 165.140.157.43 -WorkerName fleet-static-worker-server-1

04 · QA on static.*

Compare the clone to live WordPress, not to an old KV copy

  • Eyeball homepage, inner pages, popup
  • 26-check portfolio audit
  • Images, CSS, JS from R2
  • Forms + CallRail vs origin WP

Sean signs off. Do not cut over apex because the scrape “looked fine in the terminal.”

05 · Apex cutover

Same Worker. Apex + www. Keep the old per-site Worker 48 hours.

powershell -File .\scripts\Invoke-CutoverApexToFleet.ps1 -SitesCsv .\sites\YOUR.csv -IConfirmApexCutover

Adam’s API does not touch apex. We do.

06 · Form validation

Origin WP never has the fleet tag — inject after every HTML scrape

Site typeWhoFile
Remaining WordPressUsmanmu-plugin citythrive-form-validation.js (Elementor) or …-cf7-wpforms.js
Fleet / staticJohn/form-validation.js or /form-validation-cf7-wpforms.js via Cloudflare

Use fleet\assets\ copies. Not Downloads\form-validation.js (missing popup listeners).

07 · Path B · Rescrape

Already static: scrape WP through the hosting IP, skip public HTTPS

  • HTML / popup / copy only → -SkipAssets
  • Theme or media changed → full HTML + R2
  • Apex already fleet → -SkipRoutes
  • Re-inject form-validation after HTML
cd fleet\worker
powershell -File .\scripts\Invoke-WpOriginToFleet.ps1 -SitesCsv .\reports\YOUR.csv -HostingIp 174.136.29.214 -SkipRoutes -SkipAssets

08 · Path C · Edit loop

Need the CMS? Rollback apex to WordPress. Keep KV and R2.

fleet apex → rollback routes → edit on WP → rescrape origin IP → restore fleet

aaPanel dev. is optional staging. Default for an already-fleet site is Path C, not typing into KV.

10 · Proof after go-live

Headers, form JS, images, hard-refresh

  • Homepage 200 + kv + x-fleet-host
  • /form-validation.js 200 (or CF7 file)
  • Main form and popup validate with our script
  • SVGs served as image/svg+xml, never application/xml
